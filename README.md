# 🎵 Automating Spotify Playlist Creation with Terraform

> **Overview**  
Blended **Infrastructure as Code (IaC)** with creativity by using **Terraform** to automate the creation of **Spotify playlists** based on personal music preferences. A fun, real-world application of DevOps tools beyond the cloud.

## ⚙️ Key Highlights

### 🧾 Terraform Automation

- 🔗 Connected to the **Spotify Web API** using a Terraform provider
- 🎧 Created playlists **declaratively** using Terraform configuration files
- 📦 Automated playlist generation based on pre-defined genres or moods

### 📚 Learning Outcomes

- 👨‍💻 Gained hands-on experience with **custom Terraform providers** and **OAuth flows**
- 💡 Explored how **IaC principles** can be applied to **non-traditional use cases**
- 🚀 Reinforced best practices in **modular configuration** and **reusability**

---

## 🎯 Impact

- ✅ Demonstrated Terraform’s versatility beyond infrastructure management
- 🎯 Expanded understanding of API-based automation
- 🌍 Bridged the gap between **DevOps tooling** and **creative personal projects**
